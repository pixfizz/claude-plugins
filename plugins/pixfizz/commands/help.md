description: What the Pixfizz plugin can do, with example prompts
---

Show the user a short menu of what this plugin covers, in plain language, with one example prompt each:

- **Liquid and templates** (`/pixfizz:liquid`) — writing and debugging Shopper snippets, sorting and filtering Custom Types, JS that survives AJAX re-injection, CSS placement. Example: "why does my sorted collection lose its order after I filter it?"
- **Storefront UX** (`/pixfizz:ux`) — conversion review of a page or flow, vertical guidance for photo labs, gifting and school/sports, kiosk interface patterns. Example: "review my product page for conversion"
- **Storefront copy** (`/pixfizz:copy`) — hero sections, headlines, CTAs, landing page structure, social proof placement. Example: "write a hero section for my canvas prints page"
- **Pricing formulas** (`/pixfizz:pricing`) — Ruby pricing formulas, quantity and volume breaks, per-page book pricing, automatic discounts and extra fees. Example: "why is this book product overcharging for extra pages?"
- **XML templates** (`/pixfizz:xml`) — production specification for design products: sets, pages, bleed and safe area, layers, fulfillment output. Example: "set up an XML definition for a 12x12 photobook"
- **Shopify integration** (`/pixfizz:shopify`) — metafields, product linking, theme snippets, cart previews, order webhooks. Example: "the Personalize button reverts to Add to cart after a variant change"
- **Product import** (`/pixfizz:import`) — Lightspeed/Vend CSV to Pixfizz Static Product Importer, including pricing formulas. Example: "convert this Lightspeed export for import"
- **Photo book layouts** (`/pixfizz:layouts`) — generate or fill the frame arrangements customers pick from in the Design Tool, written straight into a design theme export. Example: "add twenty more one- and two-photo layouts to this theme"
- **Storefront setup and launch** (`/pixfizz:launch`) — deployment models, what to have ready, phase sequence, blockers, email templates, pre-launch checklist. Example: "what do I need in place before I can configure checkout?"

Then ask which one they want to start with. Do not dump skill contents.
